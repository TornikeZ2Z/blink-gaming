Provably fair

  1. Before bets open, the server commits to a secret server seed by publishing its SHA-256 hash.
  2. For every difficulty and intersection, HMAC-SHA256(server seed, "route:nonce:difficulty:step") shuffles the routes. The first ones in the shuffle are the safe routes.
  3. Pilots on the same difficulty fly the same map, so one pilot's choice never changes another's result.
  4. After the round the seed is revealed and every intersection can be recomputed.

Payout ladder

After n safe routes the multiplier is RTP ÷ pⁿ, where p is the chance of a safe route, rounded down to the cent. Landing at any point returns the target RTP, so no landing strategy beats another. Changes apply from the next round drawn.
